# LR Vectorscope (Native Win32)

A lightweight, high-performance real-time vectorscope for professional color correction. Designed specifically for photographers using Adobe Lightroom, Capture One, and other editing suites.

---

### [EN] Project Description

**LR Vectorscope** is a lightweight and high-performance real-time utility for color analysis. Unlike heavy video editing software, this tool works as a sleek overlay on your desktop.

#### Key Features:
* **Region of Interest (ROI) Capture:** Select your Lightroom preview area, and the scope will analyze only that part.
* **Native Win32 Rendering:** Ultra-low CPU and RAM usage via pure WinAPI and Lazarus.
* **Skin Tone Line (I-Line):** Reference vector (123°) for perfect skin tone adjustment.
* **Always on Top Mode:** Work seamlessly in your photo editor without losing sight of the scope.
* **Color Cloud Mode:** Visual representation of pixel distribution in the U/V space.
* **Localization:** English and Russian support (auto-detected).

#### Technical Specs:
* Language: Free Pascal (Lazarus).
* Rendering: Optimized GDI (32-bit buffer with forced alpha preservation).
* Performance: 30+ FPS capture rate.

#### Installation
1. Download `LRVectorscope.zip`.
2. Unpack this archive into any directory.
3. Run `LRVectorscope.exe` and enjoy!

### [RU] Описание проекта

**LR Vectorscope** — это компактная и быстрая утилита для анализа цветовой составляющей изображения в реальном времени. В отличие от тяжелых видеоредакторов, этот инструмент работает как легкий оверлей поверх вашего рабочего стола.

#### Основные возможности:
* **Захват любой области экрана (ROI):** Выберите превью в Lightroom, и прибор будет анализировать только его.
* **Нативный Win32 рендеринг:** Минимальное потребление ресурсов ЦП и ОЗУ благодаря использованию чистого WinAPI и Lazarus.
* **Линия скинтона (I-Line):** Эталонный вектор (123°) для идеальной настройки тона кожи.
* **Режим "Поверх всех окон":** Удобно работать в Lightroom, не переключаясь между окнами.
* **Цветовая индикация:** Поддержка цветного облака пикселей для визуального разделения оттенков.
* **Локализация:** Поддержка русского и английского языков (автоопределение по языку ОС).

#### Технические детали:
* Написано на: Free Pascal (Lazarus).
* Графический движок: GDI (оптимизированный 32-bit буфер с принудительным сохранением альфа-канала).
* Скорость захвата: до 30+ FPS.

#### Установка
1. Скачайте `LRVectorscope.zip`.
2. Распакуйте этот архив в любую директорию.
3. Запускайте `LRVectorscope.exe` и работайте!
